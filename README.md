# FBI Content Blocker

A Manifest V3 browser extension that blocks websites from configurable, locally bundled domain lists. It includes independent filters for core protection, adult content, gambling, misinformation, and social media.

> **Disclaimer:** This is an independent project. It is not affiliated with, endorsed by, or operated by the FBI or any government agency. The block page is generated by this extension; it is not an official seizure or government notice. Domain lists can contain mistakes, so use the filters as a configurable aid rather than a guarantee of safety or accuracy.

## What it does

- Blocks a matching top-level site or subdomain using the filters you enable.
- Provides a local, accessible block page that identifies the matched hostname.
- Lets you toggle each category or all categories from the toolbar popup.
- Stores only filter preferences locally in the browser via `chrome.storage.local`.
- Uses locally packaged lists at runtime: browsing data is not sent to a remote blocking service.

## Filter categories

| Key | Category | Source list |
| --- | --- | --- |
| `base` | Core protection | `rules/list_base.json` |
| `porn` | Adult content | `rules/list_porn.json` |
| `gambling` | Gambling | `rules/list_gambling.json` |
| `fakenews` | Misinformation | `rules/list_fakenews.json` |
| `social` | Social media | `rules/list_social.json` |

The lists are generated from [StevenBlack/hosts](https://github.com/StevenBlack/hosts). Category lists exclude domains already in the base list, so each toggle remains independent.

## Install for development

1. Open `about:debugging#/runtime/this-firefox`.
2. Choose **Load Temporary Add-on**.
3. Select this project's `manifest.json`.

## Update the lists

Run the generator with Python 3:

```bash
python3 generate_rules.py
```

The script downloads all source lists before writing output. If a download fails, it leaves the existing lists untouched.

## Test

```bash
python3 -m unittest discover -s tests
node --check background.js
node --check popup/popup.js
node --check fbi/fbi.js
```

## Change the disclaimer text

Edit [`disclaimer.js`](disclaimer.js). `DISCLAIMERS.settings` appears in the toolbar settings popup and `DISCLAIMERS.blockedPage` appears on the local blocked page. Keeping the text in this one file prevents the two notices from drifting apart.
